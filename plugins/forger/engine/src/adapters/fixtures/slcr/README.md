# slcr fixtures

Output of the `slcr` binary used to test the provider without running it.
`check.json`, `check-vet-failed.json` and `slice.txt` are the stdout captured (the breadcrumb glyph in the slice is changed to ">" for ASCII-only files) in
the snapshot tests of https://github.com/wack/slcr; `query-modality.json` has the
documented shape of `slcr query --format json`.
